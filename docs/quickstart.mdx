<Warning>Lucy is pre-beta software. Avoid using it in production; it may cause permanent data loss.</Warning>

## Install Lucy

On macOS and Linux:

```sh
curl -fsSL https://lucy.lc/sh | sh
```

The installer places Lucy in `~/.local/bin`. Add that directory to your `PATH` if needed.

On Windows, run in PowerShell:

```powershell
irm https://lucy.lc/ps1 | iex
```

The installer adds `%USERPROFILE%\.local\bin` to your user PATH. Open a new terminal to use it.

You can also install with Go:

```bash
go install github.com/mclucy/lucy@latest
```

On macOS and Linux, you can instead use Homebrew:

```bash
brew tap mclucy/tap
brew trust --tap mclucy/tap
brew install --cask lucy
```

## Adopt a server

In an existing server directory, inspect the server and create its manifest:

```bash
cd path/to/your/server
lucy status
lucy init
```

On a Fabric, Forge, or NeoForge server, add a package:

```bash
lucy add lithium
lucy install
```

To start a new server instead, see [`lucy create`](/commands/create). Run `lucy --help` or append `--help` to a command to see its options.
