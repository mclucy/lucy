Currently, we are in pre-beta stage; there will be more distribution methods in the future.

## Prerequisites

Before you begin, you must have:

- A terminal and basic knowledge of command line usage

## Get started

<Warning>Pre-beta versions are not recommended for production use and may lead to permanent data loss.</Warning>

<Steps>
  <Step title="Install">
    The current recommended way to install `lucy` is via Go's toolchain natively.

    ```bash
    go install github.com/mclucy/lucy@latest
    ```

    For macOS users, you can also use `brew` to install `lucy`:

    ```bash
    brew install --HEAD mclucy/tap/lucy
    ```

    The following distribution methods are planned for the future:

    - A `curl` install script
    - A Nix flake
    - AUR
  </Step>
  <Step title="Usage">
    After installation, you can run `lucy --help` in your terminal to see the available commands.

    ```bash
    lucy --help
    ```

    Every command also has its own help page, for example `lucy install --help`.
  </Step>
  <Step title="Run it">
    Get a comprehensive overview of your server with `lucy status`:

    ```bash
    cd path/to/your/server
    lucy status
    ```

    To manage an existing server directory, adopt it into a manifest first, then add packages and sync:

    ```bash
    lucy init
    lucy add modrinth:lithium
    lucy install
    ```

    `lucy install` syncs the directory with the lock file, resolving a new lock first when the manifest has changed. Use `lucy status` to inspect the live server, or `lucy status --from-lock` to render the lock.
  </Step>
</Steps>
