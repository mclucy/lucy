---
title: "lucy java"
description: "Inspect and choose Java for your server"
---

List the Java runtimes Lucy finds and check them against your server's requirements:

```bash
lucy java list
```

With a lock file, the list shows the requirements and which runtime Lucy selected. Without one, it lists available runtimes. Lucy warns about mismatches; you can still start the server with your own Java command or script.

## Set a server requirement

Choose a Java version and optionally a distribution for the server:

```bash
lucy java use 21 --distribution temurin
lucy install
```

`lucy java use` updates `lucy.yaml`; `lucy install` resolves the new requirement into the lock. Run `lucy java use` without arguments to choose interactively, or use `auto` to return to automatic version or distribution selection. Package requirements and Mojang's recommended Java version also affect compatibility.

## Select a runtime on this machine

To use a specific installation locally, set `java.home` with [`lucy config`](/commands/config):

```bash
lucy config set java.home /opt/homebrew/opt/openjdk@21
```

This local choice overrides automatic runtime selection. Lucy warns if it does not meet the requirements or is unusable. To install a suitable runtime when needed, see [`lucy install --java`](/commands/install#java).
