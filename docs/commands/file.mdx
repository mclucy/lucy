---
title: "lucy file"
description: "Track and restore server files"
---

Run file commands from the server workspace, using paths relative to `lucy.yaml`. Stop the server before changing tracked files.

```bash
lucy file track server.properties
lucy file list
lucy file update server.properties
lucy file history server.properties
lucy file recover server.properties
```

Tracking saves the current file as an accepted revision. Use `--immutable` to warn about changes, `--no-hash` to check presence only, or `--recover-url <url>` to provide a recovery source. Presence-only files cannot be recovered.

Use `lucy file lock <path>` to accept the current contents and warn about future changes, and `lucy file unlock <path>` to allow changes without warnings. `lucy file untrack <path>` stops tracking without deleting the file.

`lucy file recover` restores the current accepted revision; `lucy file revert` restores an earlier one. Both preserve a local copy of the contents they replace. Pass several paths to `track`, `untrack`, `update`, `recover`, `lock`, or `unlock`; use `--all` with `update` or `recover` to select all applicable files.

For step-by-step examples, see [File tracking](/file-tracking/overview) and [Recover and revert files](/file-tracking/recovery).
