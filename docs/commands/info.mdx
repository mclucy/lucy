---
title: "lucy info"
description: "Inspect a package or local mod/plugin archive"
---

```bash
lucy info modrinth:fabric-api
lucy info modrinth:lithium@0.12.4
lucy info ./mods/worldedit-7.3.0.jar
```

Use a package reference or a local `.jar`, `.pyz`, or `.mcdr` file. Bare package names use the current lock when possible; otherwise Lucy searches the applicable sources. No workspace is required.

Local files are inspected even when no upstream project matches. The optional upstream lookup uses the network. Archives containing several packages show each one separately.

Some sources provide only project-level information. Lucy warns when it cannot apply a requested version.

## Flags

<ParamField query="--long, -l" type="boolean" default="false">
  Show full descriptions, dependency constraints, and all project details.
</ParamField>

See [Global Flags](/commands/global-flags) for JSON and output options.
