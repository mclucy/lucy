---
title: "lucy compile"
description: "Build a mod from a Git repository"
---

Build a Fabric, Forge, or NeoForge mod from a GitHub repository or Git URL:

```bash
lucy compile owner/repo
lucy compile https://codeberg.org/owner/repo.git -o ./dist
```

<Warning>
  Compiling runs scripts from the repository and may download build tools and dependencies. Only compile repositories you trust.
</Warning>

You need Git, the Java version required by the project, and either the project's Gradle wrapper or a local Gradle installation. The JAR goes into the current directory unless you specify `--output` (`-o`). An output ending in `.jar` names the file; other paths name a directory. Lucy does not overwrite an existing destination.

## Select a build

Use `--branch` or `--tag` to select a revision. If the repository contains multiple builds or mod projects, specify the build directory, project, or ecosystem to choose one:

```bash
lucy compile owner/multi-platform-mod -o ./dist --build-dir fabric --project :fabric
```

`--ecosystem` accepts `fabric`, `forge`, or `neoforge`. For detailed Git and Gradle logs, add `--log-level=debug --print-logs`.

## Flags

### Arguments

<ParamField path="url|owner/repo" type="string" required>
  GitHub shorthand (`owner/repo`) or a Git repository URL to clone. Lucy checks out the repository's default branch unless `--branch` or `--tag` is set.
</ParamField>

<ParamField query="--output, -o" type="string">
  Destination for the compiled mod JAR, resolved relative to the current directory. A path ending in `.jar` names the destination file; any other value names a directory that receives the project's artifact name. Defaults to the current directory. Missing directories are created. The destination must not already exist; `lucy compile` does not overwrite files.
</ParamField>

<ParamField query="--ecosystem" type="string">
  Restrict project selection to one mod type. Accepted values: `fabric`, `forge`, `neoforge`.
</ParamField>

<ParamField query="--build-dir" type="string">
  Select a Gradle build directory relative to the cloned repository. Use this when the repository has multiple independent Gradle builds. The path must stay inside the checkout.
</ParamField>

<ParamField query="--project" type="string">
  Select a Gradle project path, such as `:fabric`, when a build contains multiple mod projects.
</ParamField>

<ParamField query="--branch" type="string">
  Checkout Git branch `BRANCH` after cloning, before compiling. Mutually exclusive with `--tag`.
</ParamField>

<ParamField query="--tag" type="string">
  Checkout Git tag `TAG` after cloning, before compiling. Mutually exclusive with `--branch`.
</ParamField>

See also [Global Flags](/commands/global-flags).
