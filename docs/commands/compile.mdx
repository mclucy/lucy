---
title: "lucy compile"
description: "Build a mod from a Git repository"
---

Build a Fabric, Forge, or NeoForge mod from a GitHub repository or Git URL:

```bash
lucy compile owner/repo
lucy compile https://codeberg.org/owner/repo.git -o ./dist
```

<Warning>
  Compiling runs scripts from the repository and may download build tools and dependencies. Only compile repositories you trust.
</Warning>

You need Git, the Java version required by the project, and either the project's Gradle wrapper or a local Gradle installation. The JAR goes into the current directory unless you specify `--output` (`-o`). An output ending in `.jar` names the file; other paths name a directory. Lucy does not overwrite an existing destination.

## Select a build

Use `--branch` or `--tag` to select a revision. If the repository contains multiple builds or mod projects, specify the build directory, project, or ecosystem to choose one:

```bash
lucy compile owner/multi-platform-mod -o ./dist --build-dir fabric --project :fabric
```

`--ecosystem` accepts `fabric`, `forge`, or `neoforge`. For detailed Git and Gradle logs, add `--log-level=debug --print-logs`.
