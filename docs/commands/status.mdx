---
title: "lucy status"
description: "Display an overview of the current server"
---

`lucy status` inspects the current directory and prints a summary of the server — server software and version, Minecraft version, runtime files, and installed packages. This is the [`neofetch`](https://github.com/dylanaraps/neofetch)/[`fastfetch`](https://github.com/LinusDierheimer/fastfetch) for Minecraft servers.

```bash
lucy status
```

No arguments. Run it from the server directory or any directory that `lucy` manages. By default, server and package names come from a live inspection of the installed files. Pass `--from-lock` to render the server and packages from `lucy-lock.yaml` instead.

```bash
lucy status --from-lock
```

## Flags

<ParamField query="--from-lock" type="boolean" default="false">
  Render the server and packages from `lucy-lock.yaml` instead of inspecting the live directory. This describes the lock file, not what is currently installed on disk.
</ParamField>

<ParamField query="--logo" type="string" default="small">
  Controls the ASCII art logo shown alongside the status output.

  | Value | Description |
  |---|---|
  | `small` | Compact logo (default) |
  | `large` | Full-size logo (opt-in) |
  | `none` | No logo |
</ParamField>

<ParamField query="--long, -l" type="boolean" default="false">
  Show full `modrinth:project`-style references instead of bare names, and expand collapsed lists.
</ParamField>

See also [Global Flags](/commands/global-flags) and [`lucy install`](/commands/install).
