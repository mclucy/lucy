---
title: "lucy status"
description: "Display an overview of the current server"
---

Show the server and installed packages in the current workspace. This command does not change files.

```bash
lucy status
lucy status --long
lucy status --from-lock
```

## Flags

<ParamField query="--from-lock" type="boolean" default="false">
  Read `lucy-lock.yaml` instead of inspecting installed files. Running activity is not observed.
</ParamField>

<ParamField query="--logo" type="string" default="small">
  Choose `small`, `large`, or `none`.
</ParamField>

<ParamField query="--long, -l" type="boolean" default="false">
  Show every package with its full reference and relative path.
</ParamField>

See [Global Flags](/commands/global-flags) for JSON and output options.
