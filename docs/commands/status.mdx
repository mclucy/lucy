---
title: "lucy status"
description: "Display an overview of the current server"
---

`lucy status` inspects the current directory and prints a summary of the server — server software and version, Minecraft version, runtime files, and installed packages. This is the [`neofetch`](https://github.com/dylanaraps/neofetch)/[`fastfetch`](https://github.com/LinusDierheimer/fastfetch) for Minecraft servers.

```bash
lucy status
```

No arguments. Run it from the server directory or any directory that `lucy` manages. By default, Lucy inspects the installed files. When the manifest and lock agree on the server, that selection stays authoritative: unrelated jars are reported as unmanaged, not as conflicting servers. Equivalent launchers of the same server also remain non-fatal. If the selected server is missing, Lucy reports it rather than switching to an unrelated jar.

When no declaration selects a server and the directory holds several, `lucy status` chooses one for display and prints a warning on stderr, including in JSON mode. The preference favors a server that loads more kinds of content: hybrid Forge/Fabric plus Bukkit runtimes first, then mod loaders, then specialized server forks, then Bukkit/Paper-family implementations, and finally plain Minecraft. A managed entry point and then a stable identity/path order break ties. The choice is read-only: status never writes it to `lucy.yaml` or `lucy-lock.yaml`. Run [`lucy init --entry-point`](/commands/init) to record a different server. Pass `--from-lock` to render the server and packages from `lucy-lock.yaml` without inspecting the installed files.

```bash
lucy status --from-lock
```

## Flags

<ParamField query="--from-lock" type="boolean" default="false">
  Render the server and packages from `lucy-lock.yaml` instead of inspecting the live directory. This describes the lock file, not what is currently installed on disk.
</ParamField>

<ParamField query="--logo" type="string" default="small">
  Controls the ASCII art logo shown alongside the status output.

  | Value | Description |
  |---|---|
  | `small` | Compact logo (default) |
  | `large` | Full-size logo (opt-in) |
  | `none` | No logo |
</ParamField>

<ParamField query="--long, -l" type="boolean" default="false">
  Show full `modrinth:project`-style references instead of bare names, and expand collapsed lists.
</ParamField>

See also [Global Flags](/commands/global-flags) and [`lucy install`](/commands/install).
