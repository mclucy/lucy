## Output and automation

Use `--no-color` to disable colors, or `--no-interactive` to disable prompts and animated progress. If a command needs a choice, `--no-interactive` fails with the flag to use instead. `--no-style` combines both options.

Commands that support machine-readable output accept `--json` or `--json-compact`. For example:

```bash
lucy status --json
lucy schema status
```

`lucy schema` lists supported commands and describes their JSON results. `lucy compile` does not support JSON output. See a command's help for its options.

## Diagnostics

Lucy writes diagnostic logs to `~/Library/Logs/lucy/lucy.log` on macOS, `~/.local/share/lucy/logs/lucy.log` on Linux, or `%APPDATA%/lucy/logs/lucy.log` on Windows. Use `--log-file <path>` to choose another location and `--print-logs` to show logs in the terminal. `--log-level` controls the displayed severity (`debug`, `info`, `warn`, `error`, or `fatal`); the file retains debug details.

Use `--use-github-mirror` if you need the GitHub release mirror for eligible downloads. Run `lucy --version` to check the installed version.
