---
title: "Global Flags"
description: "Flags available on every lucy command"
---

These flags are inherited by every `lucy` subcommand.

## Meta

<ParamField query="--version" type="boolean">
  Print the current `lucy` version and exit.
</ParamField>

## Output style

<ParamField query="--no-color" type="boolean" default="false">
  Disable ANSI colors. Text attributes such as bold or underline survive, so output stays readable in environments that do not support color or when piping output to another program.
</ParamField>

<ParamField query="--no-interactive" type="boolean" default="false">
  Disable interactive effects such as progress bars, spinners, and prompts. A command that would have to ask for input fails instead, naming the flag that carries the same choice — every interactive selection has one.
</ParamField>

<ParamField query="--no-style" type="boolean" default="false">
  Same as `--no-color --no-interactive`.
</ParamField>

`--json` and `--json-compact` are inherited by every command and render on the ones that produce machine-readable output. `--json-compact` wins when both are set.

<ParamField query="--json" type="boolean" default="false">
  Print JSON indented with 2 spaces.
</ParamField>

<ParamField query="--json-compact" type="boolean" default="false">
  Print JSON without indentation.
</ParamField>

## Logging

Diagnostic logs record action boundaries and internal decisions. Command results and user reports remain independent of these settings.

<ParamField query="--log-level" type="string" default="info">
  Set the minimum diagnostic severity: `debug`, `info`, `warn`, `error`, or `fatal`. This setting does not filter user reports.
</ParamField>

<ParamField query="--log-file" type="string" default="platform-specific">
  Append diagnostic logs to this file. Parent directories are created when needed. The command fails before its action if the destination cannot be opened.

  The default is `lucy.log` under `~/Library/Logs/lucy` on macOS, `~/.local/share/lucy/logs` on Linux, or `%APPDATA%/lucy/logs` on Windows.
</ParamField>

<ParamField query="--print-logs" type="boolean" default="false">
  Write the same filtered, timestamped diagnostic records to the log file and stderr. User reports remain independent. When an event is both logged and reported, both representations appear.
</ParamField>

## Network

<ParamField query="--use-github-mirror" type="boolean" default="false">
  Route eligible downloads through the GitHub release mirror instead of the canonical upstream URL. This is useful for users in regions with limited access to GitHub. We use https://ghfast.top for this feature.
</ParamField>
