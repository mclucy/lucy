---
title: "lucy remove"
description: "Remove mods and plugins from a server"
---

Remove one or more packages declared in `lucy.yaml`:

```bash
lucy remove modrinth:lithium
lucy remove modrinth:fabric-api modrinth:lithium
```

A dependency stays installed while another package needs it. Lucy removes files it installed that are no longer needed, but leaves your manually placed files, worlds, and server configuration alone. If removal fails, the manifest and lock remain unchanged.

Lucy normally infers the mod or plugin type from the server; use `--ecosystem` to select it explicitly. `--locked` prevents new version resolution, and `--offline` prevents network access. See [`lucy add`](/commands/add) to add a package again; specify a version if you want to pin it.
