---
title: "lucy deinit"
description: "Stop managing a server and remove lucy's files"
---

`lucy deinit` removes lucy from the current server directory: `lucy.yaml`, `lucy-lock.yaml`, and `.lucy/`. The server itself stays, including its software, mods, plugins, worlds, and configuration, so it keeps running without lucy.

<Warning>
  `.lucy/` holds the only local backups and revision history for tracked files. `lucy deinit` deletes them permanently.
</Warning>

```bash
lucy deinit
```

Run it from the server directory. The command fails when there is nothing to remove, so a wrong working directory cannot silently delete nothing.

## What remains

- Files lucy installed stay on disk but become unmanaged; later lucy commands no longer know about them.
- An isolated MCDReforged environment stays in the server directory, so its launcher keeps working.
- Your global configuration, the download cache, Java, and all worlds are untouched.

`lucy deinit` does not stop a running server or uninstall Java. Use [`lucy cache clear`](/commands/install#download-cache) to empty the shared download cache separately.

`--json` prints the removed paths. It accepts the [Global Flags](/commands/global-flags).

See also [`lucy init`](/commands/init) and [`lucy install`](/commands/install).
