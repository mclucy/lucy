`lucy` is a package manager for Minecraft servers. It provides an `npm`-like experience for server hosting and modpack management. Currently, `lucy` only provides a CLI, but a web UI is planned for the future.

With `lucy`, you can:

- Set up a server from scratch in seconds
- Adopt an existing server directory into a versioned manifest
- Add and remove mods or plugins with dependency resolution
- Pin exact versions and replay them byte-for-byte from a lock file
- Reproduce a server anywhere with one `lucy install`
- Batch these operations across multiple servers on a machine

`lucy.yaml` records what you want, and `lucy-lock.yaml` records the exact files that satisfy it, hashes included. Commit both to reproduce the server later.
