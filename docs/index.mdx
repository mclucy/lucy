`lucy` is a powerful Minecraft server/modpack management tool that provides `npm`-like experience. Currtenly, `lucy` only provides CLI but a web UI is planned for the future.

With `lucy`, you can:

- Set up a server from scratch in seconds
- Adopt an existing server directory into a versioned manifest
- Add and remove mods or plugins with dependency resolution
- Pin versions exactly and replay them byte-for-byte from a lock file
- Reproduce a server anywhere with one `lucy install`
- Batch these operations across multiple instances on a machine

... all through an unified CLI experience.
