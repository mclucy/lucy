`lucy` is a powerful Minecraft server/modpack management tool that provides `npm`-like experience. Currtenly, `lucy` only provides CLI but a web UI is planned for the future.

With `lucy`, you can:

- Setup a server from scratch in seconds
- Add/remove mods or plugins seamlessly
- Upgrade mods safely with compatibility checks
- Distribute your server configuration via a single manifest file
- Batch these operations across multiple instances on a machine
- Register and manage servers as systems services
- Build a CI/CD pipeline for scalable server management

... all through an unified CLI experience.
