## Track files

Run `lucy file track` for files that already exist. You can list several paths at once:

```bash
lucy file track server.properties config/example.json
```

Lucy saves their current contents as accepted revisions. Add `--immutable` to warn about later changes, or `--no-hash` to check only that the files exist. A presence-only file cannot be recovered.

You can also select files with shell-style patterns. Quote them so the workspace, not your shell, resolves them:

```bash
lucy file track 'config/*.json'
lucy file track 'scripts/**/*.sh'
```

`*` and `?` match within one path component, character classes such as `[abc]` and `[!abc]` match one character, and `**` matches any number of directories, including none. One invocation tracks every match atomically, and a pattern that selects no regular file fails instead of tracking nothing. Hidden files require an explicit leading dot; `.lucy` and `.git` are never selected.

To provide a recovery source when tracking a file, pass its URL:

```bash
lucy file track --recover-url https://example.com/config.json config/example.json
```

## Accept changes

After editing a tracked file, save its current contents as the accepted revision:

```bash
lucy file update config/example.json
```

You can list several paths or use `lucy file update --all`. For an immutable file, accepting the change stops warnings about the new contents.

To download and accept the current contents from a configured recovery URL, use:

```bash
lucy file update --from-source config/example.json
```

This replaces the working file; lucy keeps a local copy of the displaced contents. Unlike recovery, the downloaded contents do not have to match the previous revision.

## Change the policy

Locking a file accepts its current contents and warns about later changes. Unlocking allows changes without warnings while keeping the accepted revision.

```bash
lucy file lock config/example.json
lucy file unlock config/example.json
```

To stop tracking a file without deleting it, run:

```bash
lucy file untrack config/example.json
```
