---
title: "File tracking"
description: "Keep track of server configuration files and scripts"
---

Track files when you want to check that server configuration and scripts are present, or restore an earlier version after an unwanted change. Paths are relative to the directory containing `lucy.yaml`.

```bash
lucy file track server.properties
lucy file track scripts/start.sh
```

Lucy saves the current contents locally as an accepted revision. For a file that only needs to exist, use `lucy file track --no-hash <path>`; Lucy cannot restore its contents without a saved revision.

## Choose what to check

Tracked files are mutable by default: you can edit them without a warning. To be warned when a file differs from its accepted revision, lock it:

```bash
lucy file lock server.properties
```

Locking accepts the current contents. It does not change file permissions or prevent edits. After an intentional change, accept the new contents with `lucy file update server.properties`. Use `lucy file unlock server.properties` to stop warnings about changes; Lucy still reports the difference when you list tracked files.

## Restore files

Lucy keeps captured revisions in the workspace. These copies are not off-machine backups. A missing file can also be recovered from a configured recovery URL; see [Recover and revert files](/file-tracking/recovery).

<Warning>
  Local revisions can include unaccepted changes and secrets. Do not distribute the entire `.lucy/objects/` directory with a server pack. Lucy does not yet provide an export command.
</Warning>

Continue with [Track files and accept revisions](/file-tracking/tracking), or see [`lucy file`](/commands/file) for the available commands.
